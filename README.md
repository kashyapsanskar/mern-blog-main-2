DevBook - Blog Application with React Dashboard
Overview
DevBook is a responsive blog application designed to provide a dynamic and interactive user experience. Built with React, Node.js, and MongoDB, the platform includes features such as user authentication, private dashboards, and advanced content management.

Features
Responsive Design: Ensures smooth user interactions across all devices.

User Authentication: Secure login with Firebase and Google OAuth.

Dynamic Dashboard: Users have access to private dashboards to manage their posts and settings.

Advanced Features: Includes dark mode, image uploads, and interactive elements like comments and likes.

Reliability: Thorough testing of API routes ensures the application's performance and dependability.

Tech Stack
Frontend: React.js, HTML, CSS, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB
Authentication: Firebase, Google OAuth
Usage
User Authentication: Sign up or log in using Google OAuth.
Dashboard: Manage posts, settings, and interactions in your private dashboard.
Content Management: Create, edit, and delete blog posts with added features like image uploads and dark mode.
